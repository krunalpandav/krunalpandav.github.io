Shoot Guide — emulator + AI voice workflow

Tamaro plan (Claude Code + emulator recording → AI voice platform) kaam karse. Pan 5 vastu pehla set karvi padse, nahi to video "fake demo" jevo lagse.

1 · Demo data — aa sauthi pehla, sauthi jaruri

Khali app ke "Test User / 100 / 100" vala data no video = koi bharoso nahi kare. Recording pehla app ma saacho lagto demo data bharvo. Claude Code ne aa j data seed karva kahevu.
ShuKevo data
MahinoChalu mahino, 22-24 divas ni entries (ravivar khali)
Roj nu kaam80–140 hira/divas, thodu upar-niche — ek sarkhu nahi
Bhav2-3 alag bhav (dakhla: ₹4.50, ₹5.25, ₹6.00) — "alag bhav pan aapoaap ganay" scene mate joishe j
UpaadMahina ma 2-3 entries (dakhla: ₹5,000 · ₹3,000 · ₹2,000)
Manager mode5-6 kaarigar, saacha lagta Gujarati naam (Rameshbhai, Jigneshbhai, Sanjaybhai...) — kadi koi olakhita nu aakhu naam nahi

2 · Emulator recording settings

  • Device: Pixel-type profile, 1080×2400 — Shorts/Reels mate portrait recording j joie; Play Console + YouTube long mate landscape alag (niche)
  • Developer options ma "Show taps" ON — viewer ne dekhavu joie ke kya tap thay che
  • Animations 1x j rakhvi (off nahi) — off karso to video robotic lagse
  • Recording: adb shell screenrecord --size 1080x2400 --bit-rate 12000000 (max 3 min/file — scene-wise alag file levi, pachhi jodvi)
  • Status bar saaf: demo mode vaparo — adb shell settings put global sysui_demo_allowed 1 + battery 100/clock set — notification icons video bagade che
  • Dark mode ane light mode — banne ma ek-ek master take levo; Shorts ma je saru lage e vaparvu

3 · Scene-wise recording (Claude Code ne aapva mate)

Dar script ma timing column che. Claude Code ne aa rite kahevu:

CLAUDE CODE PROMPTRead the scene table in this HTML file (tab: [PLATFORM]). For each scene: 1. Seed the demo data described in the Shoot Guide tab (realistic Gujarati worker names, 22-24 days of entries, 2-3 different rates, 2-3 withdrawals). 2. Use adb/maestro to drive the app through the exact actions in the "Visual" column. 3. Record each scene as a separate mp4 via adb screenrecord (portrait 1080x2400 for Shorts/Reels, landscape 1920x1080 for Play Console and YouTube long video). 4. Each scene's recording must be 1-2 seconds LONGER than the script timing — editing needs trim room. 5. Name files: [platform]_scene[N].mp4 6. Do a slow, human-paced interaction — pause 0.5s after each tap, scroll naturally. No instant robotic jumps.

4 · AI voice platform — mari saachi salaah

Gujarati AI voice hamna pan mostly robotic lage che. Tamara audience (kaarigar) ne robotic Gujarati turant khabar padi jay — vishwas tya j toote. Etle aa kram ma try karo:
  1. Pehlo vikalp — voiceover j nahi: Shorts/Reels ma sauthi safal format = screen text + trending audio, avaj vagar. 80% loko mute jove che. Tamari badhi Shorts script aa rite pan chale — "Voiceover" column ne khali screen-text banavi devu. Aa karso to AI voice no prashna j nathi.
  2. Bijo vikalp — AI voice test karo: ElevenLabs / Narakeet jeva par Gujarati voice thi ek video banavo. 3-4 olakhita ne moklo, puchho: "avaj kevo lage?" Robotic kahe to vaparvu nahi.
  3. Trijo vikalp — potano avaj (long video + Play Console mate): Aa be video kayami che, varsho chalse. 30 minute nu recording che — phone ma, raatre, shaant room ma. Surti avaj AI karta 10x vadhare vechay che. Script taiyar j che, vanchvani j che.
Hybrid best che: Shorts/Reels = text + music (AI/voice ni jarur j nahi) · YouTube long + Play Console = potano avaj ek j vaar.

5 · AI platform ne shu NA karva devu

  • Auto-visuals generate na karva devu — stock footage, AI images, animated characters kai nahi. App na saacha screens j video che. AI platform khali voice/captions/music mate.
  • Auto-captions aave to Gujarati spelling check karvi — AI Gujarati captions ma bhool sami che.
  • Watermark vali free tier thi export karelu video Play Console par kadi nahi mukvu.

Editing (CapCut, free)

  • Scene clips jodo → screen text overlay (motu, Anek Gujarati jevu bold font) → music
  • Text screen na upar na 20% ane niche na 25% ma nahi — IG/YT UI dhanki de che
  • Export: Shorts/Reels 1080×1920 · YouTube long 1920×1080 · 30fps chale
